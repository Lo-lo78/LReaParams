LReaParams 0.0.70 — sorgente GitHub Ready (15 novembre 2026)

Novita': finestra Preferenze ad albero (Messages, Shortcuts, Advanced), shortcut
personalizzabili indipendenti per FX e Track, titoli configurabili con
riordino/attivazione e testo personalizzato, Ctrl+P con ripristino del parametro,
selezione tracce non contigua con primo Shift+freccia sulla traccia corrente.

Questo archivio contiene il SORGENTE, non la DLL o il setup compilati.
L'indice ReaPack e le versioni storiche NON devono essere cancellati.

1. Estrai nella cartella Git locale gia' esistente; conserva .git e index.xml.
2. Usa il comando protetto dalla radice del repository:
   Tools\push_lreaparams.cmd "Release 0.0.70 - Accessible Preferences, customizable titles and track selection"
3. Controlla il run Windows build; scarica il Setup 0.0.70 e provalo.
4. Crea la release STABILE v0.0.70 sul commit testato e allega il Setup ZIP 0.0.70.
5. Solo la pubblicazione della release attiva in automatico il workflow ReaPack.
   Verifica DLL allegata, run completato e index.xml con TUTTE le vecchie versioni.

Vedi Docs/REAPACK_SETUP_IT.md per i dettagli. Non usare push --force.
