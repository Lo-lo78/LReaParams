LReaParams 0.0.74 TEST74.5 - Render reverse navigation and sample rate
Source-only validation, 19 November 2026

Changes limited to RenderNavigation, its test/README documentation and this report.
- Alt+letter cycles forward; Alt+Shift+letter cycles backwards and wraps.
- Reverse is based on the currently focused matching HWND, else the prior
  cycle state, else the last entry for a fresh reverse cycle.
- Alt+Z is reserved for the main Sample rate input (ID 1041, with label fallback).
- Earlier Alt+S remains an alias for the same sample rate control.
- Supports native combo controls that focus a child edit.
- Existing Ctrl+F/F3, Alt+1/Alt+2, tab read-only context and native Ctrl+Tab
  are unchanged. Both accelerator directions change focus only.
- Disabled controls remain disabled and cannot be focused.
- No changes to Tools/push_lreaparams.cmd, Tools/generate_reapack_index.py,
  .github/workflows/publish-reapack.yml or the Git/ReaPack publishing scheme.
