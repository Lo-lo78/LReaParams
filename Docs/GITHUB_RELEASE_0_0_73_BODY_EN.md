# LReaParams 0.0.73 — Track Params Announcement Fix

Maintenance release (17 November 2026).

Fixes a repeated track name when opening Track Params. For example, instead of “Track 1. Track 1, Volume, 0.0 dB”, the opening announcement is “Track 1. Volume, 0.0 dB” when the title already includes the track name. Navigation behavior is unchanged.

No changes to FX Params or keyboard shortcuts. Existing guides remain valid.

The existing release workflow publishes the native DLL to ReaPack while preserving prior releases.
