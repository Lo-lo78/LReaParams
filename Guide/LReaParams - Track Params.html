This replaces the old Speak Track Params - TrackTake Navigator Lua guide (0.184). It retains the track/navigation/routing workflow while reflecting the actual C++ DLL page layout. For full FX parameter grids, Compare and the Audio Pin Connector, open the companion FX Params guide. The separate Stretch Marker script is unrelated and is deliberately omitted.

1. Installation and main idea

Install reaper_lreaparams.dll under UserPlugins in REAPER's resource path, restart REAPER, and assign a keyboard shortcut to LReaParams: Track Params in REAPER's Action List. Assign LReaParams: FX Params separately. Old launcher Lua actions and background Lua scripts are not needed for the DLL. OSARA provides speech support and NVDA can review its native keyboard window and Windows EDIT controls.

In the navigator, F1–F7 choose the seven track pages, Tab reads expanded context and NVDA+Up reviews the current field. Arrows navigate the active layout; Enter toggles editable values or opens linked operations; Alt+arrows edit supported values. Ctrl+Tab switches to the FX Params navigator if the current context has an FX; with no FX, Track Params remains open. Ctrl+Q returns focus to REAPER while supported live MIDI control continues. Esc cancels a pending operation, exits Value, goes back to Tracks, or exits the navigator depending on context.

Saved .tp page/cursor positions have a one-time page-layout migration in the DLL so the previous MIDI/hardware/ReaRoute positions can be reused. Make a backup of a project profile when first testing a migrated copy.

3. F1 — tracks

Each visible TCP track is a row; the nine fields are Volume, Pan, Width, Mute, Solo, Phase invert, Send count, Receive count and FX count. Up/Down changes the visible track while keeping the field; Left/Right changes the field. Home/End selects the first/last field; Ctrl+Home/End jumps to first/last visible track. Page Up/Down moves by pages, and repeated initial letters cycle through visible tracks. Folder states and end-of-folder boundaries are spoken, including nested folders.

Enter on Volume/Pan/Width opens or leaves Value mode; on Mute/Solo/Phase it toggles the state; on Send count/Receive count/FX count it opens F2/F3/F4. Ctrl+Enter opens/closes a folder when the current track participates in a folder, including the innermost end-folder when applicable. Ctrl+Alt+Up/Down navigates to the previous/next visible folder. These commands replace older Lua instructions where plain Enter was used to fold and Ctrl+Alt+Page was used for folder navigation.

Shift+Space toggles track selection; Ctrl+A selects all visible tracks; Delete deselects the focused track; Ctrl+Shift+Delete clears the track selection. Shift+Up/Down/Page extends a range; Ctrl+Shift+Up/Down extends to a list boundary. Keep selection separate from the spoken cursor. Ctrl+C, Ctrl+X and Ctrl+V copy/cut/paste REAPER tracks with routing (SWS/S&M is used where required). Alt+Shift+Up/Down moves selected tracks with folder-aware treatment. If a filter is active, clear it before attempting folder moves that conflict with filtered positions.

F1 creating sends and receives

Ctrl+Shift+S creates sends in a two-pass operation: select source track(s), invoke the shortcut, then select destination track(s) and invoke it again. Ctrl+Shift+R does the inverse setup for receives: select destinations first, then sources. Tab reports the pending operation. Esc cancels the pending routing step without destroying unrelated routing. F2/F3 also let you jump into an existing send/receive pair through their header field.

F1 automation

Ctrl+Shift+A toggles supported real REAPER track envelopes for Volume, Pan, Width and Mute. When an envelope is active its value may be announced with Auto. Count fields and unrelated toggles are not all automatable. Ctrl+Shift+Alt+A begins a confirmed delete-all-automation operation for the current track, including its supported track, send, receive and FX envelopes. The initial answer is No; Left/Right selects, Enter confirms the choice, Y confirms directly and Esc/N cancels.

4. F2 Sends and F3 Receives

Each routing instance occupies a column; its attributes occupy 14 rows. Left/Right switches send/receive, Up/Down moves through that instance's properties; Tab reads the routing identity and full context. A header's Enter jumps to the corresponding receive/send when available. Ctrl+Up/Down finds the previous/next visible track with routing of the page's type. Delete removes the currently selected send/receive (with REAPER Undo), rather than merely hiding it. These functions work on real REAPER routing instances, including multiple sends to the same destination.

Common attributes include Volume, Pan, Mute, Phase, Mono, MIDI follows fader, audio source mode and source/destination channel selection, send mode/type, MIDI source/destination channel and MIDI source/destination bus. Source/destination channel pairs support REAPER routing up to 128 channels, where the host and track configuration allow it. MIDI source and destination buses use their own valid ranges; MIDI merge follows source settings rather than being a free toggle. Enter toggles a boolean, opens Value for supported editable data, or reports status when the field is read-only. Alt+Up/Down modifies a value, Alt+Page Up/Down modifies in coarse steps, Alt+Home/End selects its limits. Alt+Left/Right adjusts the remembered step scale.

The route stays identified by its underlying track and send/receive relationship while other routing entries change. Do not confuse Delete here (remove routing) with Delete in F1 (deselect one track).

5. F4 — FX controls visible in the TCP

F4 is not the full FX parameter navigator. It shows the current track's FX and only the parameters exposed as REAPER Track Controls (TCP). The spoken title identifies the FX; there is no separate selectable header when an FX contains TCP parameters. The compact grid uses up to eight rows per column for the currently selected FX. Arrows navigate visible TCP parameters within that FX; Ctrl+Up/Down changes FX, Ctrl+Shift+Up/Down changes tracks with FX, and Ctrl+Page Up/Down physically reorders the FX in its chain. Ctrl+Home/End navigates to the first/last TCP parameter, whereas Alt+Home/End sets the current parameter's minimum/maximum value even in Grid.

Enter switches Grid/Value; Alt+Up/Down edits the value directly, Alt+Left/Right changes Step, Ctrl+E opens numeric edit. Ctrl+F filters visible controls by name. Ctrl+B bypasses the focused FX; Ctrl+D controls Delta Solo. Ctrl+Shift+A toggles the focused parameter's envelope; Ctrl+Shift+Alt+A begins the guarded automation clear. Delete removes only the selected control from the TCP, not the FX from the track. MIDI Fixed/Floating and per-parameter speech shortcuts also work on actual TCP parameters, stored in the project .tp.

Add missing FX TCP controls from F4

If an FX has no TCP controls, F4 announces this rather than preventing access. From any F4 position, including an FX with no visible TCP parameters, press Alt+Enter to open a names-only parameter selection grid. Choose a parameter by name. Enter adds it to the TCP and returns to F4; Ctrl+Enter adds/removes while remaining in the list. F1/F2 changes the height/column layout of the names grid; standard navigation and Ctrl+F find parameters. This is the DLL replacement for multiple historical Lua header/F6 workflows. It does not require opening a native FX window just to add a TCP knob.

6. F5 — Track MIDI (formerly F6)

F5 works for the selected track without requiring any FX in F4. It contains four editable MIDI settings plus a fifth routing entry: MIDI hardware output, hardware output channel, MIDI input channel map, MIDI control channel, and MIDI routing. Up/Down navigates; Home/End selects first/last; Tab or F5 rereads the current setting; backslash gives a short repeat. Alt+Up/Down steps ±1, Alt+Page Up/Down changes a larger step (typically four choices), and Alt+Home/End selects the extremes. Enter increments an editable field; on MIDI routing it goes to F2 or F3 if a routing instance exists. Esc from F5 ends Track Params rather than merely returning to F1. Ctrl+Tab/Ctrl+Q are still handled centrally.

7. F6 — Physical Hardware Outputs (formerly F7)

This page is for real audio device outputs, not virtual ReaRoute. F6 works even when the current track has zero hardware sends. The first virtual column is Add hardware output, followed by one column per existing physical output. Existing output columns contain these 11 rows: Hardware output, Volume, Pan, Mute, Phase invert, Mono, Audio source mode, Audio source, Hardware destination, Send type, Pan law.

Create an output entirely with the keyboard

  1. Open F6 on the desired track. On a track with no outputs, focus starts at Add hardware output.
  2. On the Add column, choose a physical device destination with Alt+Up/Down. Alt+Page Up/Down moves four choices and Alt+Home/End selects first/last. The spoken destination includes channel numbers and available audio-driver names; an unmatched final channel is offered as mono.
  3. Press Enter. The DLL creates a real REAPER hardware output and moves focus to its new 11-row column. It validates the destination after writing; if creation fails, it tries to remove the incomplete output.
  4. To add another output, press Ctrl+Home (returns to Add), choose another destination and Enter. Right from Add reaches the existing output; Left from the first output returns to Add.
  5. Select an existing output and press Delete to remove that physical output only. If it was the last, you remain in F6 on Add hardware output. Delete on Add never removes routing.

On the Add column Up/Down explores its three fields; Tab or F6 reads the current choice. On existing output columns, Up/Down moves a field, Left/Right changes output, Page Up/Down moves five rows, Home/End reaches its first/last field, Ctrl+Home returns to Add, Ctrl+End reaches the last existing output. Alt+Up/Down, Alt+Page and Alt+Home/End edit values; Enter toggles Mute/Phase/Mono or opens Value for continuous fields. Esc leaves Value first, then returns to F1. F6 reads the actual audio device's available outputs; if none are exposed, it refuses to create a phantom output. Existing ReaRoute outputs are excluded from F6 and remain on F7.

8. F7 — ReaRoute bridge (formerly F8)

F7 separates REAPER's virtual ReaRoute input and its ReaRoute output destinations. It presents a dedicated input column, an output management/Add column, then actual ReaRoute output columns, each with up to 11 fields. Left/Right moves between input/output columns; Up/Down moves through the fields; Home/End goes to the first/last field; Ctrl+Home/End moves to first/last column. Alt+Up/Down, Alt+Page and Alt+Home/End edit supported values; Enter on Add ReaRoute output creates one and on eligible cells toggles or opens Value. Delete deletes only the selected ReaRoute output, never a physical device output. Tab/F7 reads the complete routing context. Esc exits Value first, then returns to Tracks. Availability of the actual ReaRoute driver/bridge depends on REAPER's environment; this page does not install ReaRoute.

9. Common value controls and memory

Keys In F1/F2/F3/F4 as appropriate
Arrows, Home/End, Page Up/Down Navigate fields, tracks or routing columns
Enter Grid/Value; toggle; linked routing; context action
Alt+Up/Down; Alt+Page Up/Down Fine/coarse value change
Alt+Home/End Maximum/minimum on editable values
Alt+Left/Right Adjust the current stored Step (-10 to +10)
Ctrl+Backspace Reset Step to 0 for the current field
Ctrl+E Accessible numeric EDIT, Enter commits, Esc cancels
Ctrl+Shift+I Edit per-page volume range (supported Volume fields)
Ctrl+Shift+T Toggle automatic spoken value changes
Ctrl+Shift+M Open Track Memories, then Esc to return
Ctrl+F1…F12 Recall a Track Memory slot (F1)
Ctrl+Shift+F1…F12 Save a Track Memory slot (F1)
Ctrl+Z / Ctrl+Shift+Z REAPER Undo / Redo in normal track navigation when handled

Track Memories uses the common Ctrl+Shift+M command, not the old Lua Alt+F8 and not plain F8. It provides saved cursor/parameter/step/speech/MIDI/range controls in the .tp of the current project. Session-only concepts from the old script, especially Ctrl+M cursor memory and Ctrl+Shift+M detailed window titles, must not be confused with the current DLL shortcut: Ctrl+Shift+M now opens the memory manager. The standard F1 memory slots are saved into .tp when the project profile can be written, instead of relying only on the lifetime of a deferred Lua script.

10. Fixed MIDI CC, Floating CC and speech

Keys Action
Ctrl+Alt+C Arm fixed MIDI CC Learn for eligible F1/F2/F3/F4 field
Escape while learning Cancel learning and return to the current field
Shift+C Toggle the fixed CC map on/off
Ctrl+Shift+C Arm/disable Floating CC on currently selected supported field
Ctrl+Delete in a supported field Remove its fixed CC association (not track selection)
Ctrl+T Toggle MIDI CC speech for this exact target
Ctrl+Shift+T Toggle normal edited-value speech
Ctrl+Q Return focus to REAPER with eligible live MIDI still active

Fixed CC is identified by the actual track and, for F4, the FX GUID and parameter. Send/receive CC associations also distinguish their real routing instances; changing a track must not silently hand a CC to another track. The .tp project profile stores eligible fixed mappings and map preferences. Floating CC follows the current supported control, uses pickup/soft takeover and is temporary. Per-target MIDI speech defaults off; Tab and NVDA review are not silenced. In an unsupported field or an empty TCP list, Learn cannot create a meaningful mapping.

11. Filters, initial-letter search, transport and markers

Ctrl+F toggles a native Windows EDIT filter in F1/F2/F3/F4. Type the text, Enter applies, Esc cancels the edit; Ctrl+F again clears an active filter. In F1 a filter can open parent folders to reveal a matching track; F2/F3 filter routing columns, and F4 filters current TCP names / name-picker results. Normal letter navigation cycles visible names, not hidden or unrelated internal parameter IDs. Tab tells you the filter and context where applicable.

Keys Shared transport or timeline action
Space / Ctrl+Space Play/Stop / native REAPER Play-Pause
Ctrl+1…9 / Ctrl+0 Jump to marker 1…9 / 10 (time-order fallback)
Ctrl+I / Ctrl+O Previous/next marker (not region)
Ctrl+Alt+Page Up/Down One beat backward/forward
Alt+Shift+Page Up/Down One bar backward/forward
Ctrl+Alt+Shift+Page Up/Down Neighboring/current bar boundary
Alt+F10/F11/F12 OSARA Peak Watcher 1 reset / left / right
Alt+Shift+F10/F11/F12 OSARA Peak Watcher 2 reset / left / right

The timeline feedback follows the project tempo/meter map. These shortcuts do not apply to native edit fields, confirmation dialogs or unrelated REAPER windows. F10 and F11 without Alt are FX Params shortcuts, not Track Params pages.

12. Automation, storage and migration notes

Ctrl+Shift+A manages supported real envelopes for F1/F2/F3 and for F4 TCP FX parameters. Automation is indicated by the actual envelope state, not a synthetic checkbox. The confirmed Ctrl+Shift+Alt+A operation can delete all automation on the current track and therefore must be used carefully. Alt+F3/F4 in the FX Params navigator navigates automated parameters; do not assume every former Lua key is mapped identically across both DLL navigators.

Track profiles are per project in the native data folder, typically REAPER resource path/LReaParams/Tracks/*.tp, while FX-specific profiles are in Plugins/*.fx. The migration reads relevant historical Lua TXT data where supported; it does not mean old launcher scripts should still run. F5 MIDI, F6 Hardware, F7 ReaRoute are the only current Track pages above F4. F8 is free and the pin matrix is in FX F11. REAPER's project remains the canonical owner of actual tracks, envelopes and routing; the profile stores navigation preferences and custom mappings.
