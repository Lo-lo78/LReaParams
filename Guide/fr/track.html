1. Installation et principes

Installez la DLL dans UserPlugins et le dossier Guide sous LReaParams/Guide. FX Params et Track Params sont deux actions distinctes ; Ctrl+Tab passe de l’une à l’autre lorsque c’est possible. OSARA prononce les états, NVDA relit les contrôles, Tab donne les détails et Échap ferme l’édition ou la navigation.

2. Pages actuelles F1–F7

F1 Pistes ; F2 Sends (envois) ; F3 Receives (retours) ; F4 contrôles FX présents dans le TCP ; F5 MIDI de piste ; F6 sorties audio matérielles ; F7 ReaRoute. F8 est libre dans Track Params. L’ancien connecteur F5 a été déplacé dans FX Params sous F11.

3. F1 : pistes et dossiers

Haut/bas change de piste ; gauche/droite parcourt Volume, Pan, Width, Mute, Solo, Phase et les compteurs Send/Receive/FX. Entrée édite ou commute un état ; sur un compteur, elle ouvre F2/F3/F4. Ctrl+Entrée ouvre/ferme un dossier, Ctrl+Alt+haut/bas parcourt les dossiers. Maj+Espace sélectionne une piste ; Ctrl+A sélectionne les pistes visibles ; Ctrl+C/X/V copie, coupe et colle les pistes.

4. F2 et F3 : envois et retours

Les pages F2/F3 présentent les connexions, les niveaux, le panoramique et les canaux. Les flèches naviguent ; Alt+haut/bas modifie une valeur. Depuis F1, Ctrl+Maj+S crée des sends en deux étapes : sélectionnez d’abord les sources, puis les destinations. Ctrl+Maj+R effectue l’opération inverse pour les receives. Échap annule une opération en attente.

5. F4 : paramètres FX du TCP

F4 contient uniquement les paramètres FX affichés dans le panneau de piste. Ctrl+haut/bas change d’effet, Ctrl+Maj+haut/bas change de piste avec FX, Ctrl+Page précédente/suivante déplace l’effet dans la chaîne. Entrée passe en mode Valeur ; Alt+haut/bas règle ; Ctrl+E saisit un nombre. Alt+Entrée ouvre une liste des noms même si le TCP est vide. Entrée ajoute le paramètre ; Ctrl+Entrée ajoute ou retire sans quitter la liste. Suppr retire uniquement le contrôle du TCP.

6. F5 : MIDI de piste

F5 présente la sortie MIDI matérielle, son canal, la correspondance des entrées, le canal de contrôle et le routage MIDI. Haut/bas choisit la rubrique ; Alt+haut/bas change l’option ; Alt+Page précédente/suivante accélère. Tab ou F5 donne le contexte complet. Aucun FX n’est requis dans F4.

7. F6 : sorties audio matérielles

F6 affiche « Add hardware output » même sur une piste sans sortie. Dans cette colonne, choisissez une destination physique avec Alt+haut/bas et appuyez sur Entrée pour créer la sortie, sans menu natif de REAPER. Les colonnes existantes offrent Volume, Pan, Mute, Phase, Mono, source et destination. Gauche/droite change de sortie, haut/bas change de réglage. ReaRoute reste réservé à F7.

8. F7 : interface ReaRoute

F7 distingue l’entrée ReaRoute, la colonne d’ajout et les sorties virtuelles existantes. Les flèches naviguent, Alt+flèches modifie, Entrée ajoute ou active selon le champ et Suppr retire uniquement une sortie ReaRoute. Cette page n’installe pas le pilote ReaRoute.

9. Valeurs et mémoires

Entrée bascule Grille/Valeur si disponible, Alt+haut/bas ajuste, Alt+Page précédente/suivante accélère et Alt+gauche/droite modifie le pas de -10 à +10. Ctrl+E ouvre une zone numérique native. Ctrl+Maj+M ouvre Track Memories, et non F8. Ctrl+F1–F12 rappelle les mémoires ; Ctrl+Maj+F1–F12 les sauvegarde dans les contextes concernés.

10. CC MIDI et automation

Ctrl+Alt+C apprend un CC fixe, Maj+C active/désactive sa table et Ctrl+Maj+C gère le CC flottant. Ctrl+T règle la parole MIDI et Ctrl+Maj+T les changements de valeur ordinaires. Ctrl+Maj+A commande les véritables enveloppes disponibles ; Ctrl+Maj+Alt+A demande une confirmation avant de supprimer les automations. La correspondance fixe suit la piste ou la connexion réelle.

11. Filtres, transport et profils

Ctrl+F filtre les pistes, connexions ou noms TCP ; les lettres parcourent les éléments visibles. Espace et Ctrl+Espace commandent la lecture ; Ctrl+I/O parcourt les marqueurs. Les profils de piste .tp sont enregistrés par projet dans LReaParams/Tracks et les profils FX .fx dans Plugins. Les anciens lanceurs Lua ne sont plus nécessaires ; Stretch Marker est hors sujet.
