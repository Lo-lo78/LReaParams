This is the replacement for the old Speak FX Params - TrackTake Navigator Lua guide (0.346). It describes the native reaper_lreaparams.dll, using the Lua guide as the functional starting point and the current C++ source as the authority for changed behavior. The companion Track Params guide documents track controls and routing. No Stretch Marker script is part of LReaParams.

1. Installation, actions and accessibility

Put reaper_lreaparams.dll in REAPER's UserPlugins folder inside its resource path, restart REAPER, and locate LReaParams: FX Params and LReaParams: Track Params in the Action List. Assign the preferred global shortcuts there. The DLL does not require Open FX Params.lua, Open Track Params.lua, or the two original Lua navigators as launcher actions. Those Lua files are historical references, not commands to run alongside the DLL.

OSARA is required for spoken messages and shortcut-help coordination; NVDA reads the native keyboard window, its title/review, and standard Windows text-edit controls. NVDA+Up reviews the selected control; Tab requests fuller context. Keyboard capture applies only while the LReaParams navigator owns focus. If OSARA shortcut help is enabled, navigator keys are not executed as ordinary edits. Do not treat this window like a global keyboard hook.

To switch to the other workspace, use Ctrl+Tab. Esc backs out of the current editor or page and eventually exits the navigator. Ctrl+Q returns focus to REAPER while allowing the supported MIDI live-control session to stay active; it is not the same as Esc. Use the REAPER action LReaParams: Stop background MIDI to stop background MIDI explicitly.

2. Main navigation and grids

FX Params navigates track FX, take FX, Master FX, and monitoring FX within their valid contexts. Each parameter is a cell in a grid. Normal arrow keys navigate; the exact horizontal spacing depends on the grid width. F1/F2 decrease/increase the grid column count. F3 reviews Grid, Step and active Group slots or Memory slots mode. Home/End and Ctrl+Home/End navigate to local or overall boundaries as appropriate; navigation stops silently at an edge. Tab speaks the full current context; the backslash key gives a concise context announcement. Letters, digits and printable punctuation cycle through matching visible parameter names; Shift plus a printable character searches backward. The actual Windows keyboard layout is used.

Enter switches between Grid and Value for an editable parameter. In Value mode, Up/Down adjust rather than navigate; Esc returns to Grid. Alt+Up/Down adjusts the current value directly from Grid. Alt+Page Up/Down uses a coarser increment; Alt+Home/End moves to the parameter's limits. Alt+Left/Right changes that parameter's step scale from -10 to +10; Ctrl+Backspace resets only the current parameter's Step 0; Shift+Backspace resets only the current Grid to 10, or twice quickly opens numeric Grid size 1–400. Per-parameter steps are retained by the profile. Ctrl+E opens a real accessible numeric EDIT field, Enter commits and Esc cancels. If the host can only provide normalized/raw units, the edit identifies them: do not assume that a typed number is dB or Hz.

Backspace restores a parameter's default; Ctrl+Shift+Backspace invokes the broader saved Default restoration workflow (with structured ReaEQ handling where supported). Ctrl+T affects speech generated by MIDI CC for the current parameter; ordinary grid announcements and NVDA review are separate.

3. Internal FX browser — F10

F10 opens the internal FX browser from the parameter grid; in the browser, F10 (or Enter on the selected FX) loads the highlighted FX into its parameter grid. Ctrl+P no longer opens the browser: it was removed in version 0.0.61. The browser tracks FX in the current scope, with separate Master and Monitor columns when navigating that context; Left/Right switch between those two chains. The browser offers vertical selection, page jumps, first/last selection, first-character search, Tab review, bypass/offline/Delta Solo, and moving an FX without confusing movement with selection.

Ctrl+Up/Down changes the selected FX, Ctrl+Page Up/Down physically reorders it, and Ctrl+Shift+Up/Down moves to another track with FX while staying in the browser. Ctrl+B, Ctrl+Alt+B, Ctrl+D, and Ctrl+Shift+D preserve their FX actions. From the browser F11 selects the focused FX and enters its audio pin matrix, if it has usable pins. Ctrl+Shift+F and Alt+Shift+F open the native REAPER windows rather than the internal browser.

4. Audio Pin Connector — F11 (moved from Track Params)

This page is inside FX Params, not Track Params. Open F11 from Grid, Value, F7, or the internal browser, on an FX with audio pins. It works for supported Track FX, Take FX and Monitor FX. Each column is an input or output audio pin; each row is an existing track audio channel. The display covers channels 1–128 where the context and host provide them, using REAPER's two pin-mapping banks. It does not increase the track's channel count and does not manage MIDI pins.

An occupied cell begins with the concise announcement “Attive. Input 1 left. Receives from track channel 1” (similarly for Output). An empty cell has no “Disconnected” prefix: for example “Input 2 right. Receives from track channel 1”. The change is written through REAPER pin-mapping APIs with undo and readback checks. The GUID/context check avoids editing the wrong FX after a chain change. Do not use the old Track F5 or Ctrl+S pin workflow.

5. Parameter views, Custom order, F7 and Groups

Plugin order follows the FX's actual parameters and is the protected baseline. Custom order is a separately saved view that can rearrange, hide, duplicate or rename displayed occurrences without changing the plugin's real parameter numbers. Groups are independent ordered sets; changing a Group does not reorder Custom, and changing Custom does not rewrite a Group. A loaded Group can remember its last navigation position. The stored data are tied to each FX profile, not to arbitrary names in a global Parameter Library.

F7 is the deliberate structural-edit workspace: it handles selections (including snake/range selection), group or custom rearrangement, Copy/Cut/Paste of parameter occurrences, hiding/unhiding where permitted, and rename actions. Plugin order remains a reference rather than an editable reordering target. Use the available Custom/Group edit path for structural changes and leave F7 to return to ordinary parameter-value operation. Shift+arrow selects cells in F7 (the first shift movement anchors the current cell); Ctrl+Shift+Home/End extends selection to global edges; Alt+Shift+arrows travels between selected cells by grid geometry without altering selection. F7 selection and the normal parameter grid are deliberately different.

Cut is local to the edit container; Copy can transfer a selection into another eligible edit context. F7 search is a lens: filtering does not require destroying selection. Positions remembered for Group slots are independent from Custom order.

FX Memories is not F8

Press Ctrl+Shift+M or invoke the dedicated LReaParams: FX Memories REAPER action. Its columns manage saved parameter positions, Groups, copied/hidden entries, learned MIDI mappings, Default snapshots and the available profile categories. Left/Right chooses a column, Up/Down chooses an entry, Tab reviews, Enter opens/applies where supported, Delete removes or requests confirmation for destructive operations. A saved Default can restore FX values without erasing unrelated memories. Its protected Delete/reset procedure explicitly confirms before changing the stored memory configuration. Esc returns to navigation. The Lua-era instruction “F7 then F8 for the memory manager” is obsolete.

6. Compare A/B — F8

F8 once toggles Original and Compare/Edited snapshots for the current FX. Original is initially captured from the real sound when the FX is first entered; opening the navigator does not apply a snapshot or change the sound. Changes made on Compare can be recalled after listening to Original. Press F8 twice quickly to update the Original reference from the currently audible sound without toggling sides. The short delay before a single F8 action is intentional so Windows' double-press interval can be recognized. A/B snapshots are session/FX-instance state, not new plugin parameters; they survive reopening the navigator within the same REAPER session but not a new REAPER session. The former in-grid Compare virtual parameter is removed.

Fixed assignments are stored with the FX profile and use pickup/soft takeover; duplicate CC bindings can be reassigned. Floating CC is temporary and follows whichever supported parameter is selected, temporarily taking priority over fixed mappings. MIDI speech defaults to off per parameter; Ctrl+T does not mute normal navigation. Ctrl+Q may leave eligible MIDI processing running with REAPER focus. Automation indications such as Auto come from actual REAPER envelopes, not a purely visual flag. Destructive automation clearing is confirmed before execution; do not confuse it with the per-parameter Ctrl+Shift+A toggle.

8. ReaEQ, ReaComp, ReaGate and FX commands

For recognized Cockos effects the DLL offers the migrated virtual handling documented by the original Lua: ReaEQ per-band frequency/gain/bandwidth/type navigation, and special ReaComp / ReaGate controls with host readback. Real plugin values and REAPER envelopes remain the source of truth; the guide does not imply that every third-party FX exposes such virtual controls. Presets use Alt+F1/F2, bypass Ctrl+B, Delta Solo Ctrl+D, offline Ctrl+Alt+B, and FX movement Ctrl+Page Up/Down. Preserve the FX chain context when moving between track, take, Master and Monitor chains.

9. Search, clipboard and Default

Ctrl+F starts an accessible search by displayed parameter label, with Enter to accept and Esc to cancel. Ctrl+R opens saved recent searches, and Ctrl+Shift+R reads the broader FX context. The search filter affects current visible results, not the real FX parameter numbers. Outside structural editing, Ctrl+C copies a value, Ctrl+V pastes compatible value/snapshot data, and Ctrl+Alt+Shift+C copies a whole-FX snapshot. Within F7 these same clipboard keys are structural instead. Standard Windows Ctrl+A/C/X/V remains available in text EDIT fields. The Default snapshot management in FX Memories is separate from restoring a single parameter with Backspace.

11. Saved data and old Lua migration

The DLL uses its own data tree at REAPER resource path/LReaParams/; FX profiles live in Plugins (typically .fx files), track/project data in Tracks (.tp), along with its other Settings/Backups locations. It can import relevant historical Lua TXT layouts on first run/import without requiring the Lua scripts to execute. REAPER itself remains responsible for storing plugin state, real envelopes, routing and take/track FX chains in the project.

Some historical Lua behaviors do not carry over literally: Parameter Library is excluded; F8 is A/B Compare rather than an F8 memory manager; Ctrl+P is not the browser; the pin connector is F11 here, not Track F5. Do not run Lua and native navigators simultaneously. This guide is updated for the 0.0.66 release, not proof that a particular downloaded DLL has completed GitHub Actions build and NVDA/REAPER runtime verification.

TEST61.14–61.16: independent FX grids and restoration

Fourteen independent grids: Plugin Order, Custom Order, and all 12 groups independently remember their F1/F2 column count, selected parameter and precise occurrence, including duplicate entries. You do not need to enter F7 or change a parameter to save a grid position. Ctrl+L toggles Plugin/Custom; in Group mode Ctrl+F1–Ctrl+F12 selects a group, and repeating the same shortcut exits it back to its originating view.

Escape: Esc from a group grid closes FX Params immediately, retaining that group. Esc in F7 first exits its editor; F7 itself is not reopened automatically. Invalid, empty or removed groups fall back to the main grid.

Persistence: Each FX GUID keeps its own context during the REAPER session. On exit or context switch, the shared per-plugin .fx profile stores LastParam, lrp_last_navigation_v1 (active group and zero-based grid position) and lrp_context_grids_v1 (independent grid settings) in the optional [Extra] section. Older Lua keys and older profiles remain readable. After restarting REAPER the shared per-plugin profile is a fallback, not a per-GUID history of instances.

Offline/online: Ctrl+Alt+B sends the FX offline and shows FX Browser; repeating it to bring the same FX online automatically returns to its group, grid and parameter without reopening FX Params. Parameter loading is checked non-blockingly every 250 ms for up to 90 seconds. Voluntarily selecting another FX cancels that return. If no parameters appear, the browser remains usable.

Documentation: See Docs/TEST61_16_INDEPENDENT_FX_GRIDS.md in the source repository; see also README and CHANGELOG. Release TEST61.16.1 only corrects a source-only static test; it does not change the C++ runtime behavior.

LReaParams 0.0.63: TEST62 FX updates

Plugin Order, Custom Order and 12 Groups: Plugin Order always lists the complete original native parameters, unaffected by global hiding, copies and group editing. Custom Order and each group have separate occurrences and navigation grids. You can save and recall an empty group. From any group, Ctrl+L returns directly to Custom Order, including when F7 was open (which is closed); Ctrl+L again switches to Plugin Order. Repeating a group's Ctrl+F1–F12 shortcut returns to the originating context instead.

F7 structural commands: Ctrl+C copies occurrences to Custom or other groups; Ctrl+X moves within or between groups and reorders within the same context. Cutting between Custom and groups is blocked. Ctrl+Delete removes only selected occurrences from the current group; it does nothing in Custom. Ctrl+Shift+Delete hides selected parameter IDs globally in Custom and all groups, never Plugin Order, without erasing group membership. Restore individual IDs from Hidden Parameters in FX Memories. Plain Delete deselects in F7. Ctrl+Z/Y undo and redo structural edits.

F7 bulk parameter edits: Shift+Space, Ctrl+A and Shift+arrows select parameters. Alt+Left/Right sets their shared Step adjustment (-10 to +10); Alt+Up/Down and Alt+Page Up/Down update unique selected parameters using each parameter's own Step. Ctrl+E applies an exact numeric value to multiple selected parameters only when types, ranges, and formatting are compatible; incompatible sets are rejected without a partial intentional edit. ReaEQ multi-band editing requires the same band property. The normal single-parameter operations remain available.

FX Memories seven columns: Ctrl+Shift+M opens the separate manager. Copied Parameters identifies the exact group, occurrence and position, or additional Custom Order copy. Hidden Parameters holds the shared invisibility list; restoring one ID makes its preserved group entries visible again. Parameter Steps lists nonzero FX Steps; Alt+Left/Right edits the selected memory's Step and Delete resets it to zero. Shift+Space toggles selection, Ctrl+A selects the current column, Alt+Shift+Up/Down navigates selected entries in that column and Delete acts on selected entries (or current row if nothing selected). Default snapshot restore still requires explicit confirmation.

Incremental search: Quickly type letters, digits or punctuation within 1000 ms to find a prefix at the start of a parameter name or any subsequent word; repeated letters cycle matches. Shift searches backward. Shift+number searches by the physical digit key even on Italian keyboard layouts, rather than the shifted symbol. Selection is preserved. Ctrl+F still opens explicit search.

Native FX Chain: With focus on the FX Chain's own FX list, Alt+P opens FX Params for the selected plugin; plain P remains REAPER's list search, and Alt+P is untouched outside that list. Selective TXT import: From REAPER's Action List choose “LReaParams: Import selected legacy TXT files” (also in Extensions > LReaParams). Choose one or multiple compatible legacy Lua TXT files under Plugins or Tracks. Originals and existing native profiles remain intact; a differing existing destination produces an import-conflict copy instead of an overwrite.

LReaParams 0.0.64: iZotope RX 11 parameter readback

In the iZotope RX family, a formatted parameter value can be updated after the host accepts a change. FX Params now waits briefly for a stable readback before announcing changed sliders or combo-box choices, so NVDA/OSARA does not speak the previous value. This applies to Alt+arrows, Alt+Page Up/Down, Alt+Home/End, Value mode, parameter default reset, selected parameters in F7, and direct numeric editing. Rapid changes replace old pending speech; changing parameter, FX or context cancels it. A small speech delay is expected with RX, while other plugins keep their immediate readback. Profiles, keyboard shortcuts and parameter ranges are unchanged.

LReaParams 0.0.65: Keyboard theme and calibrated Page steps

14 independently saved themes per plug-in: Plugin Order, Custom Order and all 12 groups may each be Standard or Keyboard. F4 switches only the current context immediately without changing the current parameter or Step; the selected theme is stored in the plug-in .fx profile. Switching FX or context immediately loads its own saved theme. F7 is always Standard.

Keyboard: 36 deterministic keys 1–0, Q–P, A–L and Z–M select positions in the current parameter order. Unassigned keys are silent. Alt+Up/Down moves by 36-parameter pages and selects the first parameter of the new page. Up/Down, Page Up/Down, Home/End adjust values; Left/Right adjusts Step. The same Value engine is used, with calibrated Page increments guaranteed not to be smaller than arrows when the plug-in provides inconsistent increments. Existing shortcuts (Ctrl+B, Ctrl+Shift+D, Ctrl+Page Up/Down, Ctrl+Up/Down, F7, F8, MIDI and automation) are unchanged.

LReaParams 0.0.66: Keyboard Page key parity

Keyboard now uses the exact same Page Up/Down value-adjustment handler as Standard Value. The separate Keyboard interception has been removed, preserving the same selected Step, coarse Page increments, arrow behavior and value limits. This is not a new mapping or a different calibration.

Keyboard settings are unchanged: F4 switches only the current of 14 saved FX contexts. Direct numeric/letter shortcuts still select one of 36 parameters in the current block; Alt+Up/Down changes blocks, unused slots are silent and F7 stays Standard. Every other existing shortcut remains active. No profile migration is required.

GitHub Actions and ReaPack source validation now accept an existing generated index.xml as well as an archive without it; a stable GitHub release continues to publish the standalone DLL and refresh the ReaPack index automatically.

LReaParams 0.0.67: independent Grid and Step resets

In FX Params, Backspace restores the current parameter default; Ctrl+Backspace resets only the current Step; Shift+Backspace pressed once resets only the current Grid to 10 columns. Quickly pressing Shift+Backspace twice opens an accessible numeric edit field for the current Grid size (1 to 400 columns); Enter confirms and Escape cancels. Ctrl+Shift+Backspace resets all plugin parameter values, as in the earlier stable release.

Each of the 14 FX contexts retains its independent Grid and memory. F3 keeps announcing Grid, Step and Group slots / Memory slots; Alt+G and Alt+M control that last mode. Existing FX profiles and ReaPack package identifiers remain compatible.

LReaParams 0.0.67: Used parameters (Usati)

Ctrl+Shift+L toggles the new Used virtual parameter list and the previous Plugin Order, Custom Order or Group context. Used automatically collects each real FX parameter after a successful change made through LReaParams, once in first-edit order. Presets and playback automation do not populate it. Ctrl+Delete in Used removes only the entry, without changing its FX value or other groups; modifying it again adds it at the end.

Used has a separate grid, cursor and F4 Standard/Keyboard theme. The collection is stored in the REAPER project per FX GUID (save the project), not in the shared .fx profile. The original 14 contexts, F7 Standard and F3 Grid/Step/Group slots or Memory slots announcement are preserved. The speech engine calls this view Used, Italian documentation Usati.

0.0.69: Used in F7 and view persistence

Escape retains the Used view and current position when reopening the same FX. Ctrl+L exits Used directly without an unrelated Custom Order warning. In F7, Ctrl+Shift+L toggles Used with the previous editing view. Shift+Space, Shift+arrows and Ctrl+A select Used parameters. Ctrl+C copies the selected parameter IDs so they can be pasted into groups. Ctrl+Delete in F7/Used does not remove Used entries or affect underlying groups; outside F7 it still removes an entry.
