1. 安装与无障碍支持

将 reaper_lreaparams.dll 放入 REAPER 资源目录的 UserPlugins 文件夹，并将完整的 Guide 文件夹复制到 LReaParams/Guide。重启 REAPER，在动作列表中查找 LReaParams: FX Params、Track Params 和 Open User Guide，并设置快捷键。不需要再运行旧版 Lua 启动脚本。OSARA 提供语音提示，NVDA 读取导航窗口及编辑控件。Tab 朗读完整上下文，NVDA+上箭头复读当前控件。

2. 参数网格与数值编辑

使用方向键浏览参数网格。F1/F2 减少或增加网格列数，F3 朗读网格和步进信息。Enter 在网格与数值模式之间切换；数值模式中上下箭头改变数值。Alt+上/下可直接在网格中调整，Alt+Page Up/Down 大幅调整，Alt+Home/End 设置最大或最小值。Alt+左/右调整当前参数的步进级别（-10 至 +10）。Ctrl+E 打开可访问的数字输入框；Enter 确认，Esc 取消。Ctrl+Backspace 恢复 Grid 10 和 Step 0。

3. 内置效果浏览器：F10

F10 打开当前轨道、Take、Master 或监听效果链中的内部浏览器。Enter 或 F10 打开所选效果的参数网格。Ctrl+上/下切换效果，Ctrl+Page Up/Down 实际移动效果在链中的位置。Ctrl+B 切换旁通，Ctrl+Alt+B 切换离线状态。Ctrl+P 不再用于打开浏览器。Ctrl+Shift+F 和 Alt+Shift+F 打开 REAPER 原生效果窗口。

4. 音频引脚连接器：F11

Audio Pin Connector 已从 Track Params 移至 FX Params。F11 打开当前效果的音频输入/输出引脚矩阵。左/右移动到相邻引脚，上/下选择轨道声道；Enter 或空格连接/断开，Delete 移除连接。Ctrl+方向键搜索已连接单元格，Tab 或 F11 朗读当前单元格。环境允许时，通过两个引脚组支持最多 128 声道。“Attive” 表示已连接；空单元格不朗读“Disconnected”。Esc 返回原来的编辑位置。

5. 参数顺序、分组与 F7

Plugin 视图保持插件参数的原始顺序；Custom 视图可以重新排列、隐藏、复制或重命名显示项目，而不改变实际参数编号。分组与 Custom 顺序相互独立。F7 进入结构编辑：Shift+方向键选择单元格，Ctrl+C/X/V 复制、剪切、粘贴允许的项目，Ctrl+Z/Y 撤销和重做；Alt+Shift+方向键仅在已选项目中移动。Ctrl+Enter 可在支持的位置执行重命名。

6. A/B 对比与记忆

F8 对比 Original 与 Edited；快速连按两次 F8 更新 Original。F8 不是记忆管理器！Ctrl+Shift+M 打开 FX Memories。根据当前组/记忆模式，Ctrl+F1–F12 读取保存槽位，Ctrl+Shift+F1–F12 保存槽位。允许时 Ctrl+L 可切换 Plugin 和 Custom 顺序。

7. MIDI CC 与自动化

Ctrl+Alt+C 学习固定 MIDI CC；Shift+C 开关固定映射；Ctrl+Shift+C 使用带软接管的浮动 CC。Ctrl+T 切换 MIDI CC 数值语音提示。Ctrl+Shift+A 开关参数真正的 REAPER 自动化包络；开启后可能朗读“Auto”。Ctrl+Shift+Alt+A 在删除自动化前要求确认。Ctrl+Q 将焦点返回 REAPER，同时保留兼容的实时 MIDI 控制。

8. ReaEQ 等效果的特殊支持

ReaEQ、ReaComp、ReaGate 具有专用支持，在适当情况下包括虚拟参数。Alt+F1/F2 切换主机预设；Alt+F3/F4 浏览已自动化的参数。Ctrl+B 切换旁通，Ctrl+D 控制 Delta Solo。请检查 NVDA 朗读的单位，标准化数值并不一定代表 Hz 或 dB。

9. 搜索、剪贴板与恢复默认值

输入字母、数字或标点可循环查找当前可见的参数名称；按住 Shift 反向搜索。Ctrl+F 打开搜索，Ctrl+R 查看最近搜索。Backspace 恢复单个参数的默认值；Ctrl+Shift+Backspace 在可用时恢复已保存的 Default。F7 中的复制与粘贴修改显示项目，不会改变插件的真实参数顺序。

10. 播放、标记与电平监测

空格控制播放/停止；Ctrl+空格控制播放/暂停。Ctrl+I/O 跳转前一个/下一个标记，Ctrl+1–0 跳转标记 1–10。Alt+F10/F11/F12 和 Alt+Shift+F10/F11/F12 操作 OSARA 的两个 Peak Watcher。普通文本输入框中不应拦截这些快捷键。

11. 配置文件与 Lua 迁移

FX 配置以 .fx 文件保存在 LReaParams/Plugins。DLL 能导入部分兼容的旧 TXT 配置，但不需要同时运行旧 Lua 导航脚本。引脚修改通过 REAPER 原生 API 执行，不会自动增加轨道声道数。本指南对应 0.0.65，不包括独立的 Stretch Marker 脚本。

TEST61 新功能：独立网格、分组和恢复

Plugin Order、Custom Order 和 12 个分组分别记住自己的网格列数（F1/F2）以及准确的参数位置，无须进入 F7 编辑器。Ctrl+L 在 Plugin 和 Custom 间切换；在分组模式下使用 Ctrl+F1–Ctrl+F12 进入分组。在分组网格中按 Esc 会直接关闭 FX Params；在 F7 中则先关闭编辑器。当前会话按 FX 实例分别保存状态，重启 REAPER 后从同类型插件共享的 .fx 配置文件恢复。旧配置仍兼容。Ctrl+Alt+B 将 FX 设为离线并显示浏览器；重新上线后自动恢复分组、网格和参数。参数加载缓慢时最多进行 90 秒非阻塞检查。主动切换 FX 将取消恢复，F7 不会自动重新打开。

TEST62：顺序、分组、隐藏及 F7

Plugin Order 始终显示全部原始参数，包括在其他视图中隐藏的参数。Custom Order 与 12 个分组分别保存条目、副本和网格；已保存的空分组仍可使用。在 F7 中，Ctrl+C 可跨组复制，Ctrl+X 可在组间移动或在同一视图内排序，但不能在 Custom 与组之间剪切。Ctrl+Delete 仅删除当前组中选中的条目；Ctrl+Shift+Delete 在 Custom 和所有组中全局隐藏参数，但不影响 Plugin Order。通过 Ctrl+Shift+M 的 Hidden Parameters 列恢复。F7 中单独按 Delete 只取消选择。从任何组按 Ctrl+L 始终返回 Custom Order，即使 F7 已打开。

TEST62：批量编辑、Step 与 FX 记忆

在 F7 中用 Shift+Space、Ctrl+A 或 Shift+方向键选中多个参数。Alt+左右改变所选参数的 Step，Alt+上下按各自 Step 修改参数值，Ctrl+E 仅对兼容参数执行批量精确输入。FX Memories 的七列包括 Hidden Parameters、带准确组名及位置的 Copied Parameters 和 Parameter Steps。Alt+左右可调整记忆项的 Step；Delete 将其复位。FX 与 Track 两种记忆中，Shift+Space 选择行，Ctrl+A 选择当前列，Alt+Shift+Up/Down 在已选行间移动，Delete 作用于选中项。危险的 Default 恢复操作仍需确认。

TEST62：增量搜索、Alt+P 和 TXT 导入

在一秒内连续输入字母、数字或标点可构成搜索前缀，也可匹配名称内部单词的开头。重复一个字母可浏览匹配项；按住 Shift 反向搜索，包括物理数字键。搜索不会改变现有选择。仅在原生 FX Chain 列表中，Alt+P 对选中效果打开 FX Params；字母 P 仍由 REAPER 使用。LReaParams: Import selected legacy TXT files 操作可选择一个或多个旧 Lua TXT 文件进行转换，不更改原件，也不会在冲突时覆盖现有配置。

0.0.64：iZotope RX 11 参数朗读修正

iZotope RX 11 有时会在参数修改后才更新显示文本。LReaParams 会稍等新的数值稳定，再交给 NVDA/OSARA 朗读，避免读出旧值。此功能适用于 Alt+方向键、Alt+Page Up/Down、Alt+Home/End、数值模式、重置、F7 多参数编辑和数字输入。快速连续修改会取消过时的朗读；其他插件不增加延迟。

0.0.65：FX Params 的 Keyboard 主题

每个插件分别保存 14 个主题选择：Plugin Order、Custom Order 和 12 个分组。F4 仅切换当前上下文的 Standard/Keyboard，不改变当前参数或步长。1–0、Q–P、A–L、Z–M 这 36 个键按当前顺序直接选择参数；空位置保持静默。Alt+上/下切换每 36 个参数一组的页面，并选中该页第一个参数。上/下、Page Up/Down、Home/End 调整数值；左/右调整步长。Page 的较大增量已校准。Ctrl+B、Ctrl+Shift+D 等其他快捷键保持不变。F7 始终使用 Standard。主题设置保存在 .fx 配置文件中。
