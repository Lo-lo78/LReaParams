1. インストールと基本操作

DLL を UserPlugins に、Guide フォルダー全体を REAPER リソースフォルダー内の LReaParams/Guide に配置します。FX Params と Track Params は別々のアクションです。利用可能な状況では Ctrl+Tab で切り替えます。OSARA が音声を出力し、NVDA がコントロールを読み上げます。Tab は詳細確認、Esc は編集の取り消しや終了です。

2. 現在のページ F1～F7

F1 トラック、F2 Sends（センド）、F3 Receives（レシーブ）、F4 TCP に表示された FX パラメーター、F5 トラック MIDI、F6 物理ハードウェア音声出力、F7 ReaRoute です。Track Params の F8 は未使用です。旧 F5 の Pin Connector は FX Params の F11 に移動しました。

3. F1：トラックとフォルダー

上/下はトラック、左/右は Volume、Pan、Width、Mute、Solo、Phase、Send/Receive/FX 数のフィールドを移動します。Enter は値の変更や切り替えを行い、数のフィールドからは F2/F3/F4 に移動できます。Ctrl+Enter はフォルダーの開閉、Ctrl+Alt+上/下は別のフォルダーへの移動です。Shift+スペースでトラック選択、Ctrl+A ですべての表示トラックを選択。Ctrl+C/X/V はトラックのコピー・切り取り・貼り付けです。

4. F2 と F3：センドとレシーブ

これらのページには接続とその音量、パン、チャンネル設定が表示されます。矢印で移動し、Alt+上/下で調整できます。F1 で Ctrl+Shift+S を押すと、最初に送信元トラック、次に送信先トラックを選ぶ 2 段階のセンド作成が始まります。Ctrl+Shift+R はレシーブの逆順操作です。Esc は保留中の作成を取り消します。

5. F4：TCP の FX パラメーター

F4 はトラックコントロールパネル TCP に表示されている FX のパラメーターだけを扱います。Ctrl+上/下で FX を切り替え、Ctrl+Shift+上/下で FX のあるトラックを切り替え、Ctrl+Page Up/Down で FX を移動します。Enter は Value モード、Alt+上/下は値の変更、Ctrl+E は数値入力です。TCP にパラメーターがなくても Alt+Enter で名前だけの追加候補一覧を開けます。Enter で追加、Ctrl+Enter で一覧を閉じずに追加・削除。Delete は TCP 上の表示コントロールだけを削除します。

6. F5：トラック MIDI

F5 ではハードウェア MIDI 出力、出力チャンネル、入力チャンネルのマッピング、制御チャンネル、MIDI ルーティングを設定します。上/下は項目選択、Alt+上/下は値の変更、Alt+Page Up/Down は大きな変更です。Tab または F5 で詳細確認。F4 に FX がなくても利用できます。

7. F6：ハードウェア音声出力

トラックに出力が 1 つもなくても F6 には「Add hardware output」列があります。その列で Alt+上/下を使い物理出力先を選択し、Enter を押すと REAPER のルーティングメニューを開かずに作成できます。既存の出力では音量、パン、ミュート、位相、モノラル、入力元や出力先などを変更できます。左/右は出力の切り替え、上/下はフィールドの切り替え。ReaRoute は F7 で管理します。

8. F7：ReaRoute

F7 には ReaRoute 入力、出力追加、および既存の仮想出力を示す列があります。矢印で移動、Alt+矢印で編集、Enter で項目に応じて追加または切り替え、Delete で選択中の ReaRoute 出力だけを削除します。ReaRoute ドライバーのインストール機能ではありません。

9. 数値編集とメモリー

対応するフィールドで Enter は Grid/Value を切り替えます。Alt+上/下は値の変更、Alt+Page Up/Down は大きな変更、Alt+左/右は -10 ～ +10 の個別ステップ変更。Ctrl+E は標準の数値入力欄です。Ctrl+Shift+M は Track Memories を開きます。F8 ではありません。Ctrl+F1～F12 は記憶の呼び出し、Ctrl+Shift+F1～F12 は対応する位置での保存です。

10. MIDI CC とオートメーション

Ctrl+Alt+C は固定 CC の学習、Shift+C は固定マップの切り替え、Ctrl+Shift+C はフローティング CC の操作です。Ctrl+T は MIDI の値の読み上げ、Ctrl+Shift+T は通常の値の読み上げを切り替えます。Ctrl+Shift+A は対応する本物のオートメーションを変更し、Ctrl+Shift+Alt+A はオートメーション削除前に確認します。固定 CC は実際のトラックや接続と関連付けられます。

11. フィルター・再生・保存

Ctrl+F はトラック、ルーティング、TCP 名のフィルターです。頭文字キーは表示されている名前を検索します。スペースと Ctrl+スペースで再生を制御し、Ctrl+I/O はマーカーを移動します。トラックごとのプロジェクト設定は LReaParams/Tracks の .tp ファイル、FX 設定は Plugins の .fx ファイルに保存されます。互換性のある旧 Lua TXT データを取り込めますが、旧ランチャーは不要です。Stretch Marker は対象外です。
