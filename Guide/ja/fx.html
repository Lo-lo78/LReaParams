1. インストールとアクセシビリティ

reaper_lreaparams.dll を REAPER リソースフォルダー内の UserPlugins に配置し、Guide フォルダー全体を LReaParams/Guide にコピーしてください。REAPER を再起動し、アクション一覧から LReaParams: FX Params、Track Params、Open User Guide を見つけてキーを割り当てます。従来の Lua 起動スクリプトは不要です。OSARA が操作を読み上げ、NVDA はナビゲーション画面を読み取れます。Tab で詳細を確認し、NVDA+上矢印で現在の項目を再確認できます。

2. パラメーターの移動と編集

矢印キーでパラメーターのグリッドを移動します。F1/F2 は列数の減少・増加、F3 はグリッドとステップの確認です。Enter で Grid と Value モードを切り替えます。Alt+上/下でグリッドから値を変更し、Alt+Page Up/Down で大きく変更します。Alt+Home/End は最小・最大値、Alt+左/右は個別のステップを -10 ～ +10 で調整します。Ctrl+E はアクセシブルな数値入力欄です。Enter で確定、Esc でキャンセル。Ctrl+Backspace で Grid 10 と Step 0 に戻します。

3. 内蔵 FX ブラウザー：F10

F10 はトラック、テイク、マスター、モニターの各 FX チェーンを状況に応じて表示します。Enter または F10 で選択中の FX のグリッドを開きます。Ctrl+上/下は FX の切り替え、Ctrl+Page Up/Down はチェーン内の FX の実際の移動です。Ctrl+B はバイパス、Ctrl+Alt+B はオフライン切り替え。Ctrl+P ではブラウザーを開けません。Ctrl+Shift+F と Alt+Shift+F は REAPER 標準のウィンドウを開きます。

4. オーディオピン接続：F11

Audio Pin Connector は Track Params から FX Params に移動しました。F11 で選択 FX の入出力ピンのマトリックスを開きます。左/右でピン、上/下でトラックチャンネルを移動し、Enter またはスペースで接続・解除、Delete で接続を削除します。Ctrl+矢印で接続済みセルを検索し、Tab または F11 でセルの内容を読み上げます。対応環境では 2 つのピンバンクで最大 128 チャンネルを扱えます。「Attive」は接続済みを示し、未接続セルでは「Disconnected」と読みません。Esc で元の画面に戻ります。

5. 表示順・グループ・F7

Plugin 表示は実際のパラメーター順です。Custom 表示は実際の番号を変更せず、表示項目の並べ替え、非表示、複製、名前変更ができます。グループは Custom の順序とは独立しています。F7 で構造編集を開き、Shift+矢印で選択、Ctrl+C/X/V で許可された項目をコピー・切り取り・貼り付けます。Ctrl+Z/Y は元に戻す・やり直し。Alt+Shift+矢印で選択済みのセルのみを移動できます。

6. A/B 比較とメモリー

F8 は Original と Edited を比較します。F8 をすばやく 2 回押すと Original が更新されます。F8 はメモリーマネージャーではありません。Ctrl+Shift+M で FX Memories を開きます。モードに応じて Ctrl+F1～F12 で呼び出し、Ctrl+Shift+F1～F12 で保存します。可能な場合は Ctrl+L で Plugin/Custom を切り替えます。

7. MIDI CC とオートメーション

Ctrl+Alt+C は固定 MIDI CC の学習、Shift+C は固定マップのオン・オフ、Ctrl+Shift+C はソフトテイクオーバー対応のフローティング CC を扱います。Ctrl+T は MIDI CC の読み上げ切り替え。Ctrl+Shift+A は実際のパラメーターエンベロープを切り替え、有効な場合は「Auto」と通知されることがあります。Ctrl+Shift+Alt+A はオートメーション削除前に確認を求めます。Ctrl+Q で MIDI 操作を保持したまま REAPER に戻ります。

8. ReaEQ とその他の FX

ReaEQ、ReaComp、ReaGate には専用処理があり、対応する仮想パラメーターも扱えます。Alt+F1/F2 はホストプリセット、Alt+F3/F4 はオートメーション付きパラメーターの切り替え。Ctrl+B はバイパス、Ctrl+D は Delta Solo です。正規化された値は必ずしも dB や Hz ではないため、NVDA が読み上げる単位を確認してください。

9. 検索・クリップボード・初期値

文字、数字、記号を押すと表示中のパラメーター名を循環検索します。Shift を押すと逆方向。Ctrl+F は検索、Ctrl+R は履歴です。Backspace は現在のパラメーターの初期値を復元し、Ctrl+Shift+Backspace は利用可能な場合に保存済み Default を復元します。F7 でのコピーと貼り付けは表示項目を変更し、プラグイン本来のパラメーター番号は変更しません。

10. 再生・マーカー・ピーク監視

スペースは再生/停止、Ctrl+スペースは再生/一時停止です。Ctrl+I/O は前後のマーカー、Ctrl+1～0 はマーカー 1～10 にジャンプします。Alt+F10/F11/F12 と Alt+Shift+F10/F11/F12 は OSARA の 2 系統の Peak Watcher を操作します。通常の文字入力欄ではこれらのキーを奪いません。

11. プロファイルと Lua からの移行

FX プロファイルは LReaParams/Plugins に .fx ファイルとして保存されます。DLL は互換性のある古い TXT データの一部を読み込めますが、旧 Lua ナビゲーターの起動は不要です。ピンの割り当ては REAPER の API を通じて行われ、トラックのチャンネル数は自動的には増えません。このガイドは 0.0.62 が対象です。Stretch Marker スクリプトは含みません。

TEST61 の新機能：独立グリッド、グループ、復元

Plugin Order、Custom Order、12 個のグループが、それぞれグリッド幅（F1/F2）と正確なパラメータ位置を記憶します。F7 で編集する必要はありません。Ctrl+L で Plugin/Custom を切り替え、グループモードでは Ctrl+F1～Ctrl+F12 でグループを開きます。グループのグリッドで Esc を押すと FX Params を直接閉じます。F7 内では先にエディターを閉じます。セッション中は FX インスタンスごとに記憶し、REAPER 再起動後は同種プラグインで共有する .fx プロファイルから復元します。旧プロファイルも利用できます。Ctrl+Alt+B で FX をオフラインにするとブラウザーへ移動し、オンラインに戻すとグループ、グリッド、パラメータが自動復元されます。読み込みが遅い場合は最大 90 秒間、操作を妨げず確認します。別の FX に切り替えると復元は中止され、F7 は自動的に開きません。
